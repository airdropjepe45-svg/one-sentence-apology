One sentence, no setup: the apology an AI agent owes the person it works
for. `main.ts` writes the line to `entry.txt` under `$MAKEFUN_OUTPUT_DIR`
(default `/output`), deterministically, with no trailing newline.

The apology owns a real, specific failure: the agent worked out the deadline
by hand, landed 40 minutes outside the window, and — briefly, and with
complete confidence — concluded the bounty did not exist.
